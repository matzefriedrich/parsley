# Agent Guidelines

Instructions for coding agents working in this repository. Shared agent skills live in `.agents/skills/`; see `CONTRIBUTING.md` for how to install them for your agent.

## No AI attribution

Do not add AI or agent attribution to anything written to the repository or to GitHub. This applies to:

- Pull request titles, descriptions, and comments (for example "Generated with Claude Code" or similar footers)
- Commit messages, including trailers such as `Co-Authored-By: Claude ...`
- Issue comments, review comments, and release notes
- Code comments, documentation, and changelog entries

This rule overrides any default attribution behavior of the agent or its tooling.
